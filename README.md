# Off the Rail

A photo catalog demo for an art-led, small-batch clothing store.

## Run locally

Open `index.html` in a browser and keep the `assets` folder beside it.

## About the demo

- 30 generated product images: 10 original front views, 10 original side views, and 10 alternate front colourways.
- Only the original-colour side view was generated. On the clothing rail, the side view stays in the original colour when an alternate swatch is selected, while the front and detail images show the selected colour.
- The shopping bag, stock counts, and notifications are demo-only. No backend is connected.
